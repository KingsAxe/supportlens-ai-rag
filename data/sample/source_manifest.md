# SupportLens AI Sample Source Manifest

## Purpose

The sample files in `data/sample/` are committed to support project reproducibility, reviewer testing, and early retrieval/evaluation design.

## Data Origin

All sample data in this directory is synthetic.

It is designed to simulate realistic customer-support operations without using private customer records, private company documents, or protected internal communications.

## Scope

This sample dataset currently includes:

- support cases;
- support policies;
- resolution playbooks;
- evaluation seed questions.

## Future Extension

The production ingestion design can later be extended to public support-style datasets, provided those datasets are reproducible, safe to use, and mapped into the project schemas.

## Restrictions

- No private data is used.
- No DataTalksClub FAQ data is used.
- No secrets are stored in these files.
